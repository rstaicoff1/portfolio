# React Portfolio Reflection

For this assignment, I created a personal portfolio website using React and Vite. The goal was to build a website that could display information about mainly my programming projects but also a little bit about my background. I also wanted the website to be something I could potentially use in the future when applying for internships or jobs.

One of the main things I learned was how React components work together to create a website. Instead of putting everything into one file, I separated the website into different components and pages. I used React Router to allow users to navigate between the Home, Experience, Projects, and Contact pages. I also learned how dynamic routes work by using project slugs to display individual project details.

Another important part of the assignment was implementing the project search filter. I used React's useState hook to store the search input and update the displayed projects based on what the user typed. This helped me understand how state can make a website interactive without having to reload the page.

For my additional feature, I used a dark mode toggle. I used localStorage to save the selected theme so that it would remain the same even after refreshing the website. This was useful because it showed me how React can interact with browser storage.

The most challenging part was making sure all the files were organized and had the correct information and also deploying it. I ran into issues with file locations and even capitalization that prevented the website from loading. I also had problems with the YML indentation where I had to go deep into Github actions to find out that it was incorrect. I fixed these problems by correcting the files.

Overall, this assignment helped me become more comfortable with React, debugging espcially  and GitHub Pages. I now have a better understanding of how to build and deploy a multi-page React application. If I continued working on this portfolio, I would improve the design by making it more unique by adding more color and stylized font, add more project details, and continue updating it as I complete new projects.
